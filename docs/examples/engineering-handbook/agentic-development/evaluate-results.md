# Evaluate agent results

## Prerequisites

A stated success check from [task steering](/agentic-development/task-steering.md)
and the dated [model comparison](/research/model-comparison.md) that still
applies to this kind of run.

## Steps

1. Compare the run to the success check, not to a preferred writing style.
2. Read the practitioner evidence and the dated comparison for known failure
   modes.
3. If the check fails, correct with the next instruction rather than
   restarting from a blank prompt.

## Success

You can say whether the run passed and which evidence supports that
judgment. This guide is standing practice; the comparison remains a dated
research record.
