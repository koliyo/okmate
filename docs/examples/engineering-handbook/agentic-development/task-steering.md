# Task steering

Give the agent a bounded goal, the corpus it may read, and the check that
means done. Correct with the next instruction rather than restarting from a
blank prompt. This explanation is handbook guidance; it is not a product
contract. Use [Evaluate agent results](/agentic-development/evaluate-results.md)
when the run finishes.
