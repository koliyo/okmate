# Model comparison

Question: which of two harnesses better matched a fixed success check on
2026-09-01?

Findings: harness A hit the check more often on that day. Uncertainty:
single host, small n, not a policy.

Implications: cite this from [Evaluate agent results](/agentic-development/evaluate-results.md)
