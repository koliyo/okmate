# Restore from a manifest

## Prerequisites

A previously exported saved package manifest and network access to the same taps.

## Steps

1. Install the package manager.
2. Apply the saved manifest.
3. Confirm the expected binaries are on `PATH`.

## Success

The machine can build the projects you actually maintain. Cite a dated
[audit](/audits/backup-snapshot.md) for what was observed on one host; do
not treat that host as universal policy.
